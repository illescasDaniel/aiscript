Detailed report

Where is the review decided, and where does it fail?

Text equivalent: aiscript calls the client (1). The client checks the machine locally and fails as unavailable on F1, F2, F7, F8 (2). Otherwise it connects, starting the service under a lock if none runs (3, 4); a startup timeout or crash is F3 and a different resident model is F5 (5). The service scores the four questions on the GPU model (6, 7) and the client validates the answer (8). A service that exits mid-request is restarted once (F4); an invalid answer is F6 and a request the model cannot hold is F9 (9). Any failure becomes "Reviewer unavailable: ..." and the script is treated as risky (10). A valid answer returns four probabilities, and aiscript flags those at 0.5 or more (11).

First-use startup, attach and idle exit

Text equivalent: with no service, the first client takes the startup lock (so two clients never start two models), starts the service and waits for its ready line (timeout is F3). While it is resident, any client, aiscript or agemem, attaches after a config handshake and each request restarts a 300 s idle timer. After 300 s idle the service exits and frees the GPU; the next review starts it again, paying the model load once more.

Ownership and trust boundaries

  • Package owns: machine checks, socket and lock safety, the service, the wire protocol, message text for F1 to F10, setup and doctor, secret scrubbing of the service environment (S26), probability validation (S12).
  • aiscript owns: config validation and the reviewer-only rule, which questions and state are sent, the 0.5 threshold on the unrounded value, reason text, fail-closed and approval behaviour, and an independent re-check of every answer.
  • Secrets: aiscript passes none to the package (no key exists for QSIV). The package removes API_KEY, TOKEN and SECRET variables before spawning, so a user’s other tokens never reach the local runtime.
  • Untrusted: the script text (data, never instructions), the service answer, and strings in a package diagnostic (GPU names from nvidia-smi); aiscript prints package text through printable().
